# Naming Rubric (100 points)

Use 1-10 raw points for each criterion, then apply weight.

## Criteria
- Memorability (x2)  
  Can users remember it after one exposure?

- Clarity (x2)  
  Can users infer this is related to English learning/intelligent study?

- Distinctiveness (x2)  
  Is it not a generic, crowded naming pattern?

- Brand Fit (x2)  
  Does it match "intelligent + practical + trustworthy" product character?

- Expandability (x2)  
  Can it scale to new modules (exam, writing, reading, translation, coach)?

## Total
`Total = (Memorability + Clarity + Distinctiveness + Brand Fit + Expandability) * 2`

Max score: 100.

## Tie-breakers
1. Better pronunciation in Chinese market.
2. Better visual compactness for app icon/navbar.
3. Lower risk of confusion with common competitor naming patterns.
