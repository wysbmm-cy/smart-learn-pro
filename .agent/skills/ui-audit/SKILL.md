# UI/UX 审计技能

## 使用场景
- 新增页面或组件后
- 修改样式后
- 发布前检查

## 审计流程

### 1. 视觉一致性检查
- [ ] 颜色是否符合设计系统
- [ ] 字体大小/行高是否统一
- [ ] 间距是否遵循规范（4px网格）
- [ ] 图标风格是否一致

### 2. 交互体验检查
- [ ] 点击区域是否足够大（≥44px）
- [ ] 悬停/点击状态是否明显
- [ ] 加载状态是否有反馈
- [ ] 错误状态是否友好

### 3. 响应式布局检查
- [ ] 移动端（<640px）显示正常
- [ ] 平板端（640-1024px）显示正常
- [ ] 桌面端（>1024px）显示正常
- [ ] 横屏/竖屏切换正常

### 4. 可访问性检查
- [ ] 对比度是否足够（WCAG AA）
- [ ] 是否有键盘导航支持
- [ ] 表单是否有 label
- [ ] 图片是否有 alt 属性

## 注意事项
- 优先关注用户高频使用的功能
- 建议截图说明问题
- 提供具体的代码修复建议
- 使用中文输出
