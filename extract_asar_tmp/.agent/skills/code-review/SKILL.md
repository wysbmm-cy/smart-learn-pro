# 代码审查技能

## 使用场景
当用户请求审查代码、检查代码质量、或询问代码是否有问题时使用此技能。

## 审查流程

### 1. 代码风格检查
- 命名规范（变量、函数、类）
- 缩进和格式一致性
- 注释是否充分
- 文件结构是否清晰

### 2. Bug 检测
- 空指针/未定义检查
- 边界条件处理
- 异常处理是否完善
- 逻辑错误

### 3. 性能分析
- 不必要的重复计算
- 内存泄漏风险
- 算法复杂度
- 大数据量处理

### 4. 安全审查
- 输入验证
- XSS/注入风险
- 敏感数据处理
- 权限检查

### 5. 可维护性
- 代码重复
- 函数/类职责单一
- 耦合度
- 可测试性

## 输出格式

```markdown
## 代码审查报告

### 📁 文件: [filename]

#### 🔴 严重问题
- [ ] 问题描述 (行号)

#### 🟡 建议改进
- [ ] 改进建议 (行号)

#### ✅ 优点
- 好的实践

### 总结
- 整体评分: X/10
- 优先修复: ...
```

## 注意事项
- 优先关注严重问题
- 给出具体的修复建议
- 肯定代码中的优点
- 使用中文输出
