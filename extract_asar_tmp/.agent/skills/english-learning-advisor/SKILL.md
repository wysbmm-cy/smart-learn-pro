# 英语学习想法助手

## 使用场景
- 设计新的英语学习功能
- 优化现有功能的学习效果
- 调整内容格式（如深度笔记、写作模板）
- 评估功能是否符合语言习得原理

## 核心学习理论

### 1. 语言习得理论
- **输入假说 (Krashen)**: i+1 原则，内容难度略高于当前水平
- **输出假说 (Swain)**: 强调产出（说、写）对习得的重要性
- **交互假说**: 有意义的交互促进语言习得

### 2. 记忆科学
- **艾宾浩斯遗忘曲线**: 间隔重复（1天、3天、7天、14天、30天）
- **深度加工理论**: 语义层面的处理比表面处理记忆更深
- **情景记忆**: 有情境的词汇比孤立单词更易记忆

### 3. 二语习得原则
- **可理解输入**: 学习者能理解的 80-95%
- **情感过滤假说**: 低焦虑环境更利于习得
- **注意力假说**: 明确注意语言形式才能习得

## 功能设计检查清单

设计或评估功能时，检查以下要点：

### 输入质量
- [ ] 内容难度是否适配用户水平？
- [ ] 是否提供足够的语境？
- [ ] 是否有视觉/听觉多模态输入？

### 输出机会
- [ ] 用户是否有主动输出的机会？
- [ ] 输出是否有反馈机制？
- [ ] 是否支持递进式输出（单词→短语→句子→段落）？

### 记忆强化
- [ ] 是否符合间隔重复原则？
- [ ] 是否鼓励深度加工（如造句、联想）？
- [ ] 是否提供复习提醒？

### 学习动机
- [ ] 是否有即时反馈？
- [ ] 是否有进度可视化？
- [ ] 是否有成就系统？

## 常见功能建议模板

### 单词学习功能
```markdown
## 推荐设计
1. **首次学习**: 图片 + 例句 + 发音 (多模态输入)
2. **即时测试**: 拼写/选择/造句 (主动输出)
3. **间隔复习**: 1-3-7-14-30 天循环 (记忆巩固)
4. **深度笔记**: 词根词缀 + 同义词 + 经典例句 (深度加工)
```

### 写作功能
```markdown
## 推荐设计
1. **输入阶段**: 范文阅读 + 好词好句积累
2. **脚手架**: 提供结构模板 + 常用表达
3. **输出**: 自由写作 + AI 即时反馈
4. **修改**: 对比修改建议 + 二次提交
```

### 阅读功能
```markdown
## 推荐设计
1. **预读**: 标题预测 + 生词预览
2. **精读**: 划词释义 + 笔记标注
3. **拓展**: 同主题延伸阅读
4. **产出**: 摘要写作 + 观点表达
```

## 深度笔记格式建议

### 词汇条目
```markdown
## Word: **eloquent**

**Definition**: 能说会道的；有说服力的
**Pronunciation**: /ˈeləkwənt/
**Part of Speech**: adj.

### 记忆技巧
- 词根: e-(out) + loqu(speak) = 能说出来 → 有口才的
- 联想: 想象一个演说家在台上侃侃而谈

### 例句
1. She gave an **eloquent** speech about climate change.
2. His **eloquent** silence spoke louder than words.

### 搭配
- eloquent speaker / eloquent defense / eloquent testimony

### 同义词
articulate, fluent, expressive

### 反义词
inarticulate, tongue-tied
```

## 评估问题清单

设计功能前，问自己：

1. **这个功能帮助用户练习什么技能？**（听/说/读/写）
2. **用户在使用过程中是被动接收还是主动参与？**
3. **有没有即时反馈机制？**
4. **如何帮助用户将新知识与已有知识关联？**
5. **是否考虑了遗忘曲线，有复习机制？**

## 注意事项
- 避免信息过载，每次学习聚焦1-3个核心点
- 鼓励产出，不只是被动阅读
- 提供多样化的练习形式
- 使用中文输出分析和建议
